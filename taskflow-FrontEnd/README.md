# TaskFlow Frontend

Frontend for the TaskFlow project built with React + Vite.

## Features

- User Authentication (Login / Register)
- JWT Authentication
- Protected Routes
- Dashboard
- Project Management
- Add / Remove Project Members
- Task Management
- Task Filtering
- Responsive UI
- React Hook Form Validation
- Toast Notifications

## Tech Stack

- React
- Vite
- React Router DOM
- Axios
- React Hook Form
- React Hot Toast
- Bootstrap

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

The application runs on:

```
http://localhost:5173
```

## Backend

Make sure the backend server is running on:

```
http://localhost:3000
```

## Environment

The frontend communicates with the backend using Axios.

Base URL:

```js
http://localhost:3000
```
